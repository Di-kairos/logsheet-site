Logsheet

Support · Mac

Logsheet opens JSON Lines logs as a table, including files of several gigabytes. Nested fields become columns, you filter by any value, and the result exports to CSV or JSON Lines.

Open a log

  1. Choose a file in the Open window, drag it onto the window, or double-click it in Finder.
  2. The first rows appear at once while the rest of the file is indexed in the background.
  3. Right-click a cell to filter by its value, or add conditions in the filter bar. Select a row to read the full record.
  4. Click Export to save the filtered records as CSV or JSON Lines.

Which files open?

Files with one JSON object per line: .jsonl, .ndjson, .json, .log and compressed .gz. A JSON file that is a single top-level array ([ {…}, {…} ]) is not supported. Lines that are malformed or truncated are counted and shown in the table.

What is free?

Every feature works on the first 100,000 lines of any file. A one-time purchase removes the limit, so whole files open. There is no subscription.

Restore a purchase

Choose File → Restore Purchases. Use the same Apple Account you bought with.

The time filter gives odd results

Filtering by time compares the timestamps as text. It is correct when all values use the same time zone and format, as in most logs. If a log mixes time zones, the order can be wrong.

Compressed files

A .gz log is unpacked into a temporary file inside the app's own container and deleted when you close the window.
